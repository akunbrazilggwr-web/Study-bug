# Bug Hunter Lab Indonesia

Website statis edukasi keamanan aplikasi web, siap dideploy ke Vercel.

## Deploy
1. Upload folder ini ke repository Git.
2. Di Vercel pilih **Add New Project**.
3. Import repository.
4. Framework preset: **Other**.
5. Build command kosong; Output directory `.`.
6. Deploy.

## Catatan keamanan
Materi ditujukan untuk sistem sendiri atau sistem dengan izin tertulis. Jangan mengambil data, mengubah akun, atau menjalankan pengujian destruktif.
